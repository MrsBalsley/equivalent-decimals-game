GOOGLE SHEETS RESULTS SETUP

1. Create a new Google Sheet.
2. In the Sheet, go to Extensions > Apps Script.
3. Delete any starter code and paste the contents of google_apps_script_results.gs.
4. Click Deploy > New deployment.
5. Select type: Web app.
6. Execute as: Me.
7. Who has access: Anyone (or the broadest option your district allows).
8. Click Deploy and copy the Web app URL.
9. Open matching.html and practice.html in a text editor.
10. Find:
    const RESULTS_ENDPOINT = "YOUR_GOOGLE_APPS_SCRIPT_URL_HERE";
11. Replace only YOUR_GOOGLE_APPS_SCRIPT_URL_HERE with your Web app URL in both files.
12. Upload index.html, matching.html, and practice.html to the same GitHub Pages repository.

Results will appear in a tab named Results in the Google Sheet.
